# YUV444 10/12-bit and scene-change implementation

## 1. Scope

The branch starts from local commit `24f54f733`, whose parent is the SVT-AV1 mainline-derived local base. It is not descended from the separate experimental tuning branch used elsewhere in the workspace.

The feature set is deliberately narrow: 4:4:4 chroma geometry and plane handling, 10-bit 4:4:4, 12-bit 4:4:4, automatic scene-cut keyframes, and minimum scene-key interval control.

## 2. 4:4:4 model

The original 4:2:0-oriented code frequently used plane identity as an implicit proxy for chroma subsampling. That assumption is invalid for 4:4:4. The local implementation separates plane identity (Y/U/V), subsampling factors (`subsampling_x`, `subsampling_y`), and high-bit-depth storage/reconstruction width.

The 10-bit work propagates real chroma geometry through block geometry, transform, prediction, coefficient coding, filtering and reconstruction instead of using fixed half-width/half-height chroma dimensions.

## 3. 12-bit extension

The 12-bit worktree extends the validated 10-bit path instead of introducing a parallel codec path. Important changes include bit-depth-aware packed high-bit-depth pixel reconstruction; AVX2/AVX-512 fallbacks for inverse transforms that are not safe at 12-bit; 12-bit-safe warped motion sample reconstruction; widened or rescaled arithmetic where 10-bit constants were insufficient; high-bit-depth picture operators and buffer metadata; resize/super-resolution fixes; temporal filtering fixes; noise model / film-grain fixes; and rate-control / analysis fixes where fixed 10-bit assumptions remained.

The code intentionally keeps 4:2:2 outside the validated scope.

## 4. Scene-change detection

### 4.1 scd=1

`scd=1` uses the histogram/region scene detector and keyframe interval guards. `scd-min-keyint` prevents frequent scene-triggered keyframes. `keyint` / intra-period still provides the maximum interval.

### 4.2 scd=2

`scd=2` retains the histogram detector as a fast prefilter, then confirms a candidate before GOP/reference assignment. The confirmation stage works on reduced source-domain luma, estimates simple intra prediction cost per sampled block, measures motion-search inter cost against the previous scene, requires enough weakly predicted blocks to accept a cut candidate, and checks a short future window so flashes and temporary occlusions can be rejected when frames quickly become more predictable from the old scene.

This keeps the decision early enough that the encoder can build the GOP around the selected keyframe rather than forcing an intra picture after dependencies have already been assigned.

## 5. FFmpeg wrapper

`integration/ffmpeg-yuv444p10p12.patch` is a wrapper-only patch. It adds 4:4:4 raw buffer sizing, `AV_PIX_FMT_YUV444P10`, `AV_PIX_FMT_YUV444P12`, AV1 profile selection needed by 10/12-bit 4:4:4, and default SCD enablement while preserving explicit `svtav1-params` overrides.

## 6. Validation policy

The repository does not commit large media samples, generated AV1 bitstreams, DLL/EXE files or build caches. The committed smoke test creates synthetic clips at runtime and verifies 10-bit and 12-bit 4:4:4 encode/decode, reported output pixel format, `scd=2` parameter acceptance, and a post-frame-zero keyframe on an abrupt synthetic scene change.

Larger local tests also covered high-bit-depth prediction/filtering, resize/superres, intraBC and film-grain paths. Their summarized results are recorded in `Docs/YUV444_TEST_RESULTS.md`; bulky generated media remains outside Git.
